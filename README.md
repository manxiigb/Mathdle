# Mathdle 🧠

Un juego diario de lógica y razonamiento matemático. Resuelve un desafío numérico de lógica sencillo nuevo cada día con intentos limitados, obtén retroalimentación direccional (muy alto / muy bajo) y mantén viva tu racha.

## 🚀 Tecnologías

* **Frontend:** React + Vite + TypeScript
* **Estilos:** Tailwind CSS
* **Fórmulas:** KaTeX
* **Backend y Base de Datos:** Supabase (PostgreSQL + RLS)

## 🎮 Características

* **Un problema diario:** Sincronizado para todos los usuarios.
* **Sistema de pistas:** Desbloquea una ayuda a cambio de un intento.
* **Cuentas simples:** Registro mediante nombre de usuario para guardar el historial y las rachas sin necesidad de correo electrónico.
* **Cálculos seguros:** Las respuestas y evaluaciones se procesan de forma segura a través de funciones RPC en Supabase, evitando trampas desde el cliente.
